# java-example0

A minimal Java 21 console application that prints `Hello, World!`.

## Run

- Click **Run**, or run `javac -d out src/main/java/Main.java && java -cp out Main`.
- The compiled classes are written to `out/` and are ignored by Git.

## Requirements

- JDK 21 (`java` and `javac`)
- No Java frameworks or external dependencies
